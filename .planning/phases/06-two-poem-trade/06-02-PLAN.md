<objective>
Ship the client contract half of the trade:
- SessionView decodes the server's trade fields tolerantly.
- Backend.tradeBack is mirrored in APIClient, LocalBackend and FakeBackend.
- Mock mode walks the full trade arc.
- AppModel can trade back from the reveal, follows the partner's answer by polling only while the server says the trade is open, and ignores late writers once the user lets the poem go.

The Reveal affordance, its copy, and the keepsake changes (D-04, D-05) are Plan 03.

Locked decisions implemented here (06-CONTEXT.md):
- D-02's client half: the app only offers or accepts when the server's view says tradeOpen, and declining, leaving or lapsing leaves today's reveal and dissolution intact.
- D-03's mock half: LocalBackend's author for poem N starts one seat later, mirroring Session.AuthorOf's poem offset.
- D-06's mock half: the mock robot poet accepts after its think time and never offers.

Orchestrator defaults honored: no new timers (the mock reuses strangerThinkTime), no new identifiers or persisted keys, an old server never shows a trade, and LocalBackend/FakeBackend parity for the protocol change.

Discretion calls (reversible, recorded):
- tradeBack returns the updated SessionView and throws, like submitLine, because the UI must learn "offered" vs "poem 2 began". The server's 409 trade_closed maps to the existing APIError.wrongTurn, so no new error case is added.
- A trade transition does not bump the epoch, because it is the same session and the same token. release() now does bump it.
- At the reveal, a 410 closes the trade but keeps the poem on screen. Today a lapsed reveal is noticed only when the user lets go, and that still happens: let it go plays the dissolution as today.
- The mock human stranger always offers at poem 1's reveal after its think time, so the accept state can be designed against on one simulator. This is recorded as DRIFT.

Purpose: the server contract (Plan 01) gets its client mirror, and the AppModel state machine gains the trade arc that Plan 03's UI renders.
