## Phase Goal

**As a** developer, **I want to** have the on-device logic (syllable counting, keepsake naming, the mock backend, and the full AppModel arc) pinned by fast, deterministic unit tests, **so that** regressions are caught without a human at a simulator.

> This restates the ROADMAP Phase 2 **Goal:** line and adds nothing (see 02-01-PLAN.md).

This plan delivers the pure-logic slice (IOST-01, IOST-02). It leads with the riskier half, PoemNaming goldens, which depend on the stdlib's seeded shuffle and so must be captured on the pinned simulator runtime, not on the macOS host (RESEARCH Pitfall 5). It then grows the Phase 1 Syllables seed into the full characterization table and adds the 5/7/5 threshold tests.

<objective>
Pin keepsake naming end to end on the simulator runtime. Capture golden poem→name pairs from current code, commit them, and prove that a hash mutation and a PRNG mutation each fail a named test. Then expand Syllables into a table-driven characterization, with the known misses pinned and not fixed, and pin the 5/7/5 targets through `SessionView.currentTarget`. Prove that a heuristic mutation fails a named test.

Purpose: IOST-01, IOST-02, and ROADMAP Phase 2 success criterion 2. It also closes the phase with a full-suite timing check (criterion 5).
Output: three test files: one new suite, one extended suite, and one new threshold suite. No app code changes.

Depends on plan 02-03 only to serialize use of the single pinned simulator (see the wave note in 02-01-PLAN.md). These suites need nothing from the other plans.
</objective>

These contracts were read from source during planning:
- `ios/Strangewords/Naming/PoemNaming.swift`:
  - `enum PoemNaming { static func coin(from lines: [String]) -> CoinedName? }`
  - `struct CoinedName: Equatable { let lead: String; let name: String; let kind: String }`
  - The seed is `fnv1a(lines.joined(separator: "\n").lowercased())`, with FNV offset basis `0xcbf29ce484222325` and prime `0x100000001b3`.
  - `SeededGenerator` is SplitMix64 with constants `0x9E3779B97F4A7C15`, `0xBF58476D1CE4E5B9`, and `0x94D049BB133111EB`.
  - Content words are letters-only tokens of 3+ characters, minus stopwords, de-duplicated, and title-cased.
  - It returns nil when there are no content words. It uses the stdlib `shuffle(using:)` and `randomElement(using:)`, which is why the goldens are runtime-sensitive.
- `ios/Strangewords/Syllables/Syllables.swift`:
  - `enum Syllables { static func count(_ text: String) -> Int }`
  - It lowercases, splits on non-letters, counts vowel clusters over `Set("aeiouy")`, drops a trailing "e" when the count is above 1, and floors a non-empty word at 1.
- `ios/Strangewords/Net/Models.swift`:
  - `SessionView(sessionId:you:participantCount:status:form:currentLine:currentAuthor:yourTurn:lines:)`
  - `currentTarget` returns `form.targets[currentLine]`, or nil when `currentLine` is outside `0..<targets.count`.
  - `FormView(id:targets: [Int?])`.
- `ios/StrangewordsTests/SyllablesTests.swift` (Phase 1 seed): `struct SyllablesTests` with `word(_:_:)` (rows ("fire", 1) and ("", 0)) and `haikuLine(_:_:)` (row ("A frog jumps into the pond", 7)). Its header says Phase 2 owns the known misses.
