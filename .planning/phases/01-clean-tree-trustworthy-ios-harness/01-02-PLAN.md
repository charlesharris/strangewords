## Phase Goal

**As a** developer, **I want to** start from a deliberate, reconciled tree where every existing check passes and run the iOS test suite headlessly, **so that** I get a pass/fail verdict that cannot report a false green.

> The story is restated from the ROADMAP Phase 1 **Goal:** line with no added content. That line is not in canonical user-story form; run `/gsd-mvp-phase 1` if you want it formalized in ROADMAP.md.

This plan delivers the second half, on top of the tree that plan 01-01 reconciled: a hosted test target, a headless runner whose verdict comes from the result bundle, and committed, re-runnable proof that the verdict cannot lie (HARN-02, HARN-03).

<objective>

Purpose: HARN-02 and HARN-03, and ROADMAP Phase 1 success criteria 3-5. Phase 2 (iOS suites) and Phase 3 (contract tests) need a test target and a runner they can trust. Phase 4's verify.sh composes `scripts/test-ios.sh` through its exit code and evidence dir.
