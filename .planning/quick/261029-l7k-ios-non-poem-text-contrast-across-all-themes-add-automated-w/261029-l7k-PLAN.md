## Contrast model (the contract ContrastTests encodes)

Math (WCAG 2.x). sRGB channel linearization: c/12.92 if c <= 0.04045, else ((c+0.055)/1.055)^2.4. L = 0.2126R + 0.7152G + 0.0722B. ratio = (Lhi+0.05)/(Llo+0.05). Opacity and backings composite source-over in gamma-encoded sRGB: out = a*fg + (1-a)*bg per channel. That matches the default CoreAnimation compositing.

Size classes. Normal text needs 4.5. Large text needs 3.0, where large means >= 24pt, or >= 19pt at semibold or heavier. That is WCAG's 18pt / 14pt-bold read with 1 iOS pt treated as 1 CSS px, the conservative reading; Apple HIG's looser 18pt cut is not used. Non-text controls need 3.0. Sizes are the declared defaults; Dynamic Type only makes them larger, which only relaxes the threshold.

Placements and their backdrop sets (every member is composited with the phase dusk first):
- sky: y in [0.32, 0.52] of screen height. Covers the sky bands whose rows meet that range: band k is present iff [y0/h*4, y1/h*4] (clamped to 0...4, h = theme horizon) intersects the open interval (k-1, k+1). That gives bands 2-4 for nature and fantasy and bands 1-4 for sci-fi. Sci-fi also adds far and near (the skyline). Dusk alpha = 0.02 x depth (the linear layer reaches only 0.02 by y = 0.52).
- low: y in [0.30, 1.00]. Covers the sky bands met by that range, plus far and near for every theme. This takes in both keyboard states: with the keyboard up the writing area sits at about 0.30-0.60; with it down the their-turn copy sits at about 0.67-0.74 and the exits at about 0.90-0.96. Dusk alpha = 0.5 x depth.
- chrome (controls that already carry a backing): all 5 bands plus far and near. Dusk alpha = 0.5 x depth. The backdrop is onAccent at the control's own opacity, composited over each scene color.
- sheet: skyBottom (opaque presentationBackground). card: onAccent at 0.6 over skyBottom.
- A backed sky or low surface uses onAccent at Legibility.backingOpacity (0.6), composited over each dusked scene color.
- Excluded point decorations (document these in the test header): stars, motes, clouds, blossoms, lit windows, antennas and beacons, celestial discs and glows. The discs sit above 0.33. Nature morning's sun reaches 0.33 only at x <= 34%, left of the centered copy, within 5% of band 2's luminance. Also excluded: dissolution text (a fade-out animation), disabled ritual labels (WCAG 1.4.3 exempts inactive components), the system confirmationDialog, and the dev chips (dev builds only).

Per-surface ratio = min over the backdrop set b of contrast(composite(roleColor, opacity, over: b), b). best = the max over the 256 sRGB grays v/255 at full opacity of the min over the same set: the best ratio ANY text color could reach there. A cell is FIXABLE iff best >= threshold.
