# Phase quick-261029-k47 Plan 01: Theme selector in settings Summary

**A quiet "scenery" card in the settings sheet lets users pick nature, sci-fi or fantasy; the choice persists as `pref.theme`, repaints the app live, and keeps dev overrides working through a pure `Themes.resolve` precedence resolver.**

## Performance

- **Duration:** 3 min
- **Started:** 2026-10-29T19:42:28Z
- **Completed:** 2026-10-29T19:44:51Z
- **Tasks:** 2
- **Files modified:** 6 (1 created, 5 modified)

## Accomplishments

- Settings sheet has a second row card, "scenery", below the unchanged robot-poet row. It lists every registered theme as a 44pt option button; the current choice shows a filled checkmark circle and the `.isSelected` trait. Ink glyphs, Theme tokens only, 4pt-multiple spacing, no accent.
- `SettingsStore.themeID` / `AppModel.themeID` persist the id under `pref.theme`. Init normalizes an absent or unknown stored id to nature in memory and never writes the key. The choice survives `leave()`, `reset()` and `TokenStore.clear()`.
- `Themes.resolve(devOverride:forced:preferred:)` pins precedence. RootView paints through it, clears only the chip override on a settings pick, and cross-fades scenery changes like a time-of-day change.

## Decisions

- **Precedence:** dev chip > `SW_FORCE_THEME` > stored choice > nature. Unknown ids fall through to the next layer, so a retired id cannot blank the scene.
- **Chip-clear:** a settings pick sets the chip override back to nil (never `SW_FORCE_THEME`). `run.sh` sets `SW_DEV=1`, so the chips are always present in dev sessions; without the clear, a tester who touched the chip would never see their pick take effect.
- **Pinned copy:** title `scenery`; helper `the world your poem is written in. only you see it.` Option labels are each theme's lowercase `name` (`nature`, `sci-fi`, `fantasy`), so a theme added to the registry appears automatically.
- **Vertical list over segmented control:** a system segmented picker renders in the system font (ignoring Theme tokens), its tint fights the palette, and it does not wrap at accessibility Dynamic Type sizes. Accent stays reserved for the robot-poet switch's on-tint.
